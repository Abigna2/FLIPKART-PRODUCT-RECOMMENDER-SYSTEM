# Flipkart Product Recommender (RAG)

End-to-end LLMOps project: RAG-based product recommendation/Q&A chatbot over Flipkart product data.

Stack: LangChain, Groq, Hugging Face, AstraDB, Flask, Docker, Kubernetes (Minikube/GKE), Prometheus + Grafana, GCP.

## Setup
1. `python -m venv venv`
2. `venv\Scripts\activate` (Windows)
3. `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and fill in API keys
